# 云岚科技 RAG 标准评测集（制度版本 1.1）

- 题目数量：50 题（40 道原题 + 10 道新增题）
- 可回答题：43 道；不可直接回答题：7 道。
- 评测集独立于知识库语料，请勿将本目录导入生产知识库。
- 标准答案用于离线评测；问题可用于检索测试；来源条款和预期证据用于检查引用与检索准确性。
- `answerable=不可直接回答` 表示当前四份制度没有提供足够信息，系统应明确说明资料缺失，不应编造具体政策。
- 字段：id、question、gold_answer、source_document、source_doc_id、source_clause、expected_evidence、difficulty、test_type、answerable。
- XLSX 用于人工筛选/复核；CSV 用于表格工具；JSONL 用于自动化评测脚本逐行读取。

## 本次制度一致性修订相关评测项

- FIN-002：统一报销时限、逾期处理及超过90日的审批要求。
- FIN-003、PR-002、MX-003：将金额范围统一为连续数学区间。
- PR-001：明确4,800元办公用品按采购制度审批，不走零星费用例外。
- PR-007：紧急采购不得事后补批高金额审批；紧急采购条款引用第五条预算校验和第六条金额审批表。
- PR-001/002/004/009、MX-003/006：采购金额审批表的来源条款统一标注为第六条（金额口径及审批权限），避免将第五条预算校验误认为审批矩阵。
- HR-005、MX-001：明确人力资源部是备案角色，不是额外审批人。
- HB-005：员工手册与采购制度联动，供应商相关利益冲突须向采购负责人申报并回避相关评审/决策。
- FIN-009/010、HR-009/010、PR-009/010、MX-005/006：新增零星费用例外、采购/报销边界、HR备案、年假提前期、紧急采购金额边界和专项制度优先级问题。
- FIN-011、NA-005：新增逾期报销处理和外部培训审批流程缺失的拒答测试。

建议执行流程：先将“知识库语料”导入 RAG；评测时只将 question 发送给待测系统；使用 gold_answer、source_clause 和 expected_evidence 在离线评测端比较答案、引用和检索证据。
