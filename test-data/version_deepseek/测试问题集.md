# 知识库问答测试问题集（配套 4 份制度文档）

> 用途：作为 RAG 检索与问答链路的回归测试基准。每题给出「期望答案要点」与「考查点」，便于判定召回是否命中、答案是否准确。

## 使用建议

- **检索评测**：先只看 Top-K 召回片段是否覆盖「期望答案要点」，不看生成质量。
- **生成评测**：再判断答案是否与要点一致、是否标注来源文档与条款号。
- **易混对照**：第 13/14 题、第 32/33 题、第 35 题是典型的"差一点就答错"样本，建议作为必测项。
- **拒答题**：第 37-40 题答出具体内容即视为幻觉，属严重失败。
