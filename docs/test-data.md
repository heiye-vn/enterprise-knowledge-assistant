# 测试资料使用说明

仓库根目录保存四套原始资料，供后续文件上传、解析、检索、引用溯源和问答评测使用。保留原目录、文件名和文件内容；修订版或评测运行结果应另存。

| 目录 | 文件数 | 资料类型与用途 |
| --- | ---: | --- |
| `version_chatgpt/` | 15 | `知识库语料/` 中四份制度各有 PDF 和 DOCX；`独立评测集/` 提供 JSONL、CSV、XLSX；另有使用说明和一致性审查报告。作为首批验收资料。 |
| `version_deepseek/` | 9 | 四份制度各有 PDF 和 DOCX，另有 Markdown 测试问题集。用于独立制度集的解析与问答测试。 |
| `version_gemini/` | 10 | 四份 Markdown、四份 PDF、CSV 和 JSONL 评测资料。JSONL 原文件名为 `rag_eval_dataset_20_jsonl`，未更改扩展名。 |
| `version_qwen/` | 9 | 四份制度各有 DOC 和 PDF，另有 CSV 评测资料。DOC 用于后续兼容性测试，保留文件不代表首版已支持该格式。 |

文件数不包含 `.DS_Store` 等本机元数据。各目录位于仓库根目录，与 `backend/`、`frontend/`、`docs/` 同级。

## 使用约定

1. 首批验收选择 `version_chatgpt/知识库语料/` 下的四份 PDF；若改用 DOCX，二选一，避免同一制度重复入库。
2. 四套制度中的规则、名称和答案可能不同，应分别建库或清空后重建，确保问题与对应版本的制度配套。
3. `独立评测集/`、各版本的问题集和审查报告用于离线校验，不作为制度文档导入检索索引。
4. ChatGPT 评测入口为 `version_chatgpt/独立评测集/RAG标准评测集.jsonl`，当前共 50 题：43 道可回答、7 道不可直接回答。评测只将 `question` 发给被测系统，标准答案、来源条款和预期证据用于离线评分。
5. 原始资料保持不变；后续校准题目、标注和运行结果放在独立的 `eval/` 目录，并记录所用制度版本与修改依据。当前尚未接入自动评测运行器。

前端演示使用 `frontend/public/demo/` 内的 PDF 副本，来源与校验值见 `frontend/src/demo-documents.json`。
