# 15～20 分钟操作演示脚本

本脚本按当前真实实现编排，电脑端录制。录制前先启动 README 中的基础设施、Worker/Beat、API 和前端；打开 127.0.0.1:5174。原有四份制度与制度图片已经处理好，不需在录屏时重新上传全部文件。

## 录制前准备（不计入视频）

- 按 README 健康检查确认本地依赖 ready、Worker pong；用一条知识问题确认模型连通。
- 原始语料放在 test-data/version_chatgpt/知识库语料；评测问题和标准答案保持独立，不上传。
- 备用上传文件为 [演示会议预约说明](../test-data/demo/演示会议预约说明.md)。如果之前已上传，可使用文档删除清理这份演示资料，保留正式制度。
- 预先打开 LangSmith 项目，使用最近一次真实请求的 Trace ID；避免录屏时处理登录。
- 网络环境应保持稳定。云解析或向量请求失败时，使用页面“重试处理”；不要临时改模型或密钥。正式制度已就绪，可继续展示已有知识问答。

## 0～2 分钟：项目目标与技术结构

展示三个页面：问答工作台、文档管理、知识图谱。

讲解：系统将企业资料转为可检索知识；通用对话、企业知识、联网查询分别决定依据来源。React/FastAPI 负责交互与 API，PostgreSQL/pgvector 存会话和向量，RustFS 存原件，Celery/Redis 负责后台任务，Neo4j 存有依据的制度关系。

可展示 README 的完整流程图，按“上传 → 解析 → 切块 → 召回 → 重排 → 回答 → 引用”说明一次请求。

## 2～5 分钟：上传、去重、预览与切块

1. 在文档管理查看现有 PDF、DOCX 和制度图片；简要切换正文/原件/切块。
2. 上传“演示会议预约说明.md”，等待可检索，再上传同一文件，展示指纹去重。
3. 提问“根据演示会议预约说明，会议应提前多久预约？”，核对 2 小时及来源。

讲解：SHA-256 识别原始字节一致的文件；PDF/Word/图片使用 MinerU，Markdown 本地解析；就绪前不参与问答。页码、章节和切块身份用于来源定位。

## 5～9 分钟：有据问答、边界和追问

依次使用以下问题，按视频时长选择两到三个：

- “一项预计4,300元的日常费用，应该经过哪些人审批？”：直属主管→部门负责人，说明采购规则另有适用范围。
- “连续请4个工作日的年假，需要谁审批？”：直属主管→部门负责人，人力资源部是备案角色。
- “公司每个月几号发工资？”：当前资料没有具体日期，应明确缺少依据。
- 先问“我这笔报销应该找谁审批？”，待澄清后补充“一项日常费用，预计4300元。”：展示上下文补全。

点击一个引用核对原文，再打开文档切块。讲解：来源编号和范围由后端校验；没有依据的结论不能用常识补全。

## 9～11 分钟：检索详情、流式与停止

展开检索详情，指出 BM25、向量距离、RRF、重排分数及最终引用。说明分数不是答案正确率。

新建会话问“请分五点介绍 RAG 的工作流程”，观察增量输出，中途停止，再重新生成。草稿允许排版，但引用和链接在完成校验前不可用。

## 11～15 分钟：知识图谱和两跳来源

1. 进入知识图谱，搜索“不超过1个工作日”，选择规则并核对适用条件与原文。
2. 使用展开/收起、节点与关系列表，说明图关系来自实际条款。
3. 问“员工要请半天事假，员工手册要求遵循哪份制度？具体由谁审批？”。
4. 展开图谱证据路径，展示员工手册 → 考勤与休假管理制度 → 审批规则。

讲解：这是有明确制度关联的两跳证据扩展，最终仍需回查原文；有关系不代表能推断未规定的审批人。问“外部培训具体由谁审批？”时仍可能拒答。

## 15～17 分钟：联网工具与追踪

开启联网查询，问“Python 3.14.0 正式版何时发布？”，核对官方发布日期和 Python.org 链接。展开工具详情，显示真实查询、网页数、最终引用与耗时。

在 LangSmith 按 Trace ID 打开真实请求：chat 中有问题/答案，knowledge.retrieve 中有片段和分数，answer_stream 中有模型输入/输出，联网分支有 tavily.search。当前调试环境已开启正文记录，配置密钥脱敏。企业制度问题仍走知识库。

## 17～20 分钟：删除、评测和交付说明

1. 删除刚上传的“演示会议预约说明”，说明后续检索会排除，历史引用仍可核对；正式资料保留。
2. 打开 [首轮验收索引](../eval/README.md)，展示 20 个案例、来源与逐题记录，以及失败发现和修复过程。
3. 展示 README 的快速启动和模型配置名称，不展示私有 Key。
4. 说明边界：本轮覆盖 20 个案例，尚未跑完整 50 题；MCP、限定文档范围和复制回答等暂缓。

压缩为 15 分钟时，减少重复问答和格式预览，保留有据回答、拒答、图谱、多跳、联网、追踪及评测结果。
