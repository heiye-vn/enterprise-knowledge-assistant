# Demo 闭环与范围收敛

2026-11-14 按用户提供的题目收敛：读取制度文档、自然语言提问、按文档回答并给出来源、无依据明确拒答。先完成这四项，不把企业级文档管理、图谱和流式协议作为交付前置条件。

## 页面

- 默认进入问答工作台；无文档也可创建会话和发送消息。问候与使用说明可以正常回应；没有制度依据时回复“未找到相关依据”。
- 文档页保留上传、按名称查找、状态和查看原文；移除无编辑能力的分类、版本选择、上传新版本、重建索引和重新解析入口。
- 来源保留“文档正文 / 文档原件 / 文档切块”。切块展示内容、章节、页码与正文定位，去掉处理代次和版本管理信息。
- 回答的引用号和来源按钮均打开真实来源；会话与消息保存到 PostgreSQL，刷新后可从历史恢复。
- 一个上传文件作为一份文档使用。为兼容现有资料和引用，底层旧 version/job 标识暂保留；本轮没有新增表或做破坏性合表迁移。相关后台历史接口暂留兼容，不继续扩展其产品能力。

## 问答

`POST /api/sessions {id}`、`GET /api/sessions`、`GET /api/sessions/{id}` 和 `POST /api/chat {session_id, client_request_id, text}`。

服务端读取最近完成的对话，简短追问附上上一轮问题用于检索。历史只辅助理解，不作为制度事实来源。检索固定当前已发布来源；模型只能依据本轮来源作答，无法支持时拒答。来源编号由模型选择，后端从保存的切块附加真实引文，避免要求模型转抄原文。程序校验引用号、范围和引文后，将回答与引用同事务保存。

通用问题先由模型直接回答；企业问题则交给知识库检索，缺少依据时拒答。明确询问本公司制度、补贴等问题时，程序强制要求知识库依据。模型/存储故障返回服务错误，不能伪装成“没有依据”。失败答案不展示为成功；同请求 ID 重试不重复生成。当前用普通 JSON 请求返回完整回答和来源，页面显示等待状态，流式输出后续按演示需要追加。

## 验证

后端 169 项、前端 35 项测试；Ruff、Alembic check、Node 22 构建通过。新增测试覆盖空库建会话/问候/拒答、会话恢复、真实 PG 引用、请求幂等、无效引文/编号拒绝、故障区别于拒答和追问上下文。

真实使用现有《员工手册》验证离职交接回答、账号权限追问、固定住房补贴拒答及来源打开。云接口发生过连接错误，失败明确展示且不生成答案；验收记录保留在 git 忽略的 `.local/demo-chat-qa/`。仅清理本轮登记的验收会话，现有员工手册及其切块、原件保持不变。

## 对话体验修正

恢复“中国国土面积”等通用问题的大模型回答，并标注“通用回答”，不冒用知识库来源。问题路由与通用回答共用一次模型调用；制度问题再检索文档并校验来源。

“新建会话”只打开本地空白页，重复点击提示“已经是新会话”。POST /api/chat 在第一条消息到来时，同事务创建会话和消息；历史列表排除没有消息的旧空会话。历史项增加删除按钮和确认，DELETE /api/sessions/{id} 使用现有 deleted_at；删除后隐藏历史并禁止继续读取或发送消息，生成中的会话需等待结束再删除。保留原记录，不批量删除用户已有空会话。

本轮后端 174 项、前端 36 项通过。真实模型返回中国国土面积约 960 万平方公里；员工离职归还资产返回实际来源。曾发生连接超时，作为服务错误展示，重新验证后正常。浏览器覆盖重复新建、首条发送、删除确认及删除后的历史状态。只清理登记的临时会话，保留现有文档和用户会话。
